### Stub routes (Option A)
The brief's Step 5 expected tests to FAIL with ImportError because route modules
did not exist. Per the task coordinator's instruction, Option A was chosen:
create minimal stub route files so the app is importable and tests pass now.
Each stub contains `from fastapi import APIRouter` + `router = APIRouter()`.
The dashboard stub additionally defines `GET /dashboard` returning the four keys
the skeleton test asserts on (`current_task`, `recent_tasks`, `data_overview`,
`llm_overview`). Tasks 6-10 will replace these stubs with real endpoints.

### httpx2 dev dependency
`starlette.testclient.TestClient` (used by the skeleton test) requires an HTTP
client. starlette 1.3.1 prefers `httpx2` (falls back to `httpx` with a
deprecation warning). Neither was installed. Added `httpx2>=2.0.0` as a dev
dependency via `uv add --dev httpx2`. Installed `httpx2 2.5.0` (+ `httpcore2`,
`truststore`). Existing `fastapi 0.139.0` / `starlette 1.3.1` / `uvicorn 0.51.0`
were unchanged.

## Concerns

1. **httpx2 dependency added beyond the brief.** The brief did not mention a
   test HTTP client, but `TestClient` cannot run without one. Added `httpx2` as
   a dev dependency. This is a necessary, minimal addition. Note: pyproject.toml
   now has `pytest` under `[project.optional-dependencies] dev` while `httpx2`
   is under `[dependency-groups] dev` — a slight inconsistency introduced by uv
   0.9.17's preference for dependency-groups. Both work with `uv sync`; could be
   unified later.

2. **`requires-python = ">=3.9"` vs httpx2 2.5.0 (needs >=3.10).** The venv is
   Python 3.13.3 so runtime is fine, but the declared `requires-python` is now
   slightly inaccurate. uv resolved it against the real interpreter. If strict
   3.9 support is required, either bump `requires-python` to `>=3.10` or pin
   `httpx2==2.0.0`. Not blocking.

3. **`@app.on_event("startup")` is deprecated** in FastAPI 0.139.0 (emits
   DeprecationWarning). Kept per brief; a future task may migrate to the
   `lifespan` ASGI handler pattern.

4. **Pre-existing analysis test failures** (4 tests) remain in the working tree.
   Out of scope for Task 5; flagged for whichever task owns the analysis layer.

5. **`get_runner` and `OBSIDIAN_OUTPUT_DIR` imported but unused** in app.py.
   Transcribed verbatim from the brief; `get_runner` will be consumed by route
   modules in Tasks 6-10. Harmless unused imports for now.
